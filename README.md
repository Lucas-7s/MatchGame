# MathGame 🎮

**MathGame** é um jogo interativo desenvolvido em **C#**, inspirado no livro *"Use a Cabeça C# (4ª Edição) 2024"*. Criado como parte do processo de aprendizado, este projeto demonstra habilidades práticas e conceitos fundamentais da linguagem C#. 

O jogo tem um estilo semelhante ao clássico *jogo da memória*, desafiando os jogadores a testarem e aprimorarem suas habilidades matemáticas enquanto se divertem.

---

## 🧠 **Objetivo do Projeto**
O **MathGame** foi projetado para:
- Consolidar os conceitos aprendidos no livro *"Use a Cabeça C#"*.
- Demonstrar o progresso no aprendizado da linguagem **C#**.
- Criar uma aplicação interativa que combina lógica, memória e matemática.

---

## 🛠 **Tecnologias Utilizadas**
- **Linguagem:** C#
- **IDE:** Visual Studio 2022
- **Plataforma:** Windows Forms (WinForms)

---

## 🎯 **Funcionalidades**
- **Modo de Jogo**: Resolva pares de equações ou problemas matemáticos.
- **Níveis Progressivos**: Aumenta a dificuldade conforme o jogador progride.
- **Pontuação**: Avalie seu desempenho ao final de cada rodada.
- **Design Interativo**: Interface simples e funcional para usuários de todas as idades.
